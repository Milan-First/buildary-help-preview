Contractor SPP Window ​

Performed Works between representatives of the (main) contractor and the client (investor) are carried out in the Contractor SPP process.

To work in this window, the user must have the appropriate permissions configured, i.e. the company and role assigned under Project Team Members, as described in the "Setting Permissions" section of the Help.

The window is divided into several separate sections, as shown in the following image:

Window Header ​

The window header is used to set and display information that is essential for working in the window. The information about the period, client, and contractor determines which set of budget items and work statements is displayed and processed in the window.

Period – Select a period from the available options. Creating a new period is described in a separate section of the Help.

Client – If you represent the client, only the organization to which you are assigned is available. If you represent the contractor, all clients appearing in the project budget are available.

Contractor – If you represent the contractor, only the organization to which you are assigned is available. If you represent the client, all contractors appearing in the project budget are available.

Reports – Opens a window containing a list of Measurement Reports for the Client/Contractor pair selected in the header. A Measurement Report (ZP) is a report documenting Performed Works between a Client/Contractor pair or, where applicable, a Contractor/Subcontractor pair for a specific period.

INFO

Each ZP can have one of the following statuses:

  • Draft
  • Approval
  • Proposal Change
  • Closed

Change Measurement Report Status – This section displays buttons for changing the ZP status. The available buttons depend on the current status of the Measurement Report. Changes to the ZP status are protected by permission groups, as described in the "Setting Permissions" section of the Help.

Summary Panel ​

The Summary Panel provides an overview of information for the entire project from the perspective of the selected Client/Contractor pair.

White section of the panel – Displays total amounts for all periods.

Colored section of the panel – Displays amounts related to the period currently selected in the window header.

  • the home icon indicates that data for all project items is displayed
  • the filter icon indicates that the displayed data is aggregated only from items matching the currently selected filter.

Items and Consumption in the Current Period ​

If no filter is active, the window always displays the items contained in the project parts selected in the Project Structure panel, for example, the items belonging to the first project object.

The item window contains several groups of columns:

Item – columns containing item codes and descriptions. The Type distinguishes between a building object, project part, section, and individual items. The checkbox column is used to select items for Bulk Operations. The item name column contains an "i" icon that allows you to display detailed information about the item in a separate window.

Remaining – this group of columns contains information about the remaining quantity and price of the item. The remaining value is also represented by an icon showing the percentage.

Selected Period – this group of columns is used to enter and approve item consumption for the selected period. The columns in this group are displayed dynamically based on the status of the Measurement Report and the user's permissions. Editable cells are highlighted in yellow. The speech bubble icon allows you to add a note to the item's consumption. An orange icon indicates that a note exists. Work in this group is described in detail below.

Completed – this group of columns contains information about the completed quantity and price of the item. The figures also include consumption for the Selected Period.

Budget – displays information about the total quantity and price of the items. The unit price of each item is also displayed.

Item Details – the window displays descriptive information about the item. It also provides summary information about its consumption status and a detailed breakdown of consumption by individual periods. The consumption details also show who approved the consumption and when. Notes related to the consumption are also available, if entered.

Project Structure ​

The Project Structure panel makes it easier to navigate the budget. The panel displays building objects, project parts, or budget sections. The structure can contain multiple levels with practically no limit.

Each level can be expanded to display the next level.

The grid then displays only the items belonging to the group selected in the Project Structure panel.

If you need to display a larger range of items, you can select multiple records in the tree using multiselect (Ctrl+click or Shift+click). Ctrl+click can also be replaced by pressing and holding the mouse button.

The panel displays a symbol and the number of unresolved and resolved items for the selected period next to each record. This is a very useful navigation aid for large projects when entering, approving, and modifying items.

The project structure tree can be expanded and collapsed in bulk using the control buttons above the panel.

The project structure can also be filtered based on the occurrence of a specified string.

The "Hide Panel" button can be used to create more space for displaying the grid contents.

Special Functions Panel ​

Bulk Operations ​

– opens a list of functions that can be used to modify data for multiple items at once. Bulk Operations are always applied to the items selected (checked) in the grid. If you need to select multiple items, you can use the checkbox at a higher level.

Consumption by Amount – distributes the entered amount among the selected items. The maximum amount that can be consumed is the sum of the remaining prices of the selected items. If both positive and negative items are selected, there is no unambiguous algorithm for reaching the requested resulting price. In this situation, a positive amount is distributed only among positive items, while a negative amount is distributed only among negative items. The user is informed about this procedure by a message displayed directly in the application.

Consumption by Percentage – consumes the specified percentage of the item's total quantity for each selected item. Enter only the value, without the % symbol.

If the quantity calculated from the specified percentage exceeds the item's remaining quantity, the item is consumed only up to its total quantity. This operation therefore cannot result in overconsumption. Change Item Status – changes the status of the selected items to the selected status value. This option is available only when the Measurement Report is in the "Approval" status.

Delete Consumption – deletes all entered data for the selected items and resets them to their default status. This option is available only when the Measurement Report is in the "Approval" status.

Before performing a Bulk Operation, you can choose whether the item selection should remain active after the operation is completed. This can be useful if you want to perform another Bulk Operation on the same set of items.

INFO

You can easily clear the item selection by double-clicking the header of the checkbox column. The first click selects all displayed items, while the second click clears the selection for all items.

Filtering ​

The filtering menu offers predefined filters divided into three groups, depending on which information is used for filtering. The filter is always applied to all project items, so it also affects which records are displayed in the Project Structure panel. If a particular level of the structure contains no items matching the filter, that level will not be displayed in the tree.

Item Status – allows you to filter items according to their current status. In addition to individual statuses, summary statuses can also be selected.

  • Open – items with the status Draft or In Negotiation, i.e. items that have not yet been resolved.

  • Closed – items with the status Approved, Change, or Rejected, i.e. items that are considered resolved.

Consumption in the Selected Period – allows you to filter items based on whether consumption has been entered for the selected period.

  • Consumed – have a non-zero value in the Invoiced Quantity column.

  • Not Consumed – have no value or a zero value in the Invoiced Quantity column.

Consumption in All Periods – allows you to filter items based on whether consumption has been entered in at least one period.

  • Consumed – have a non-zero value in the Invoiced Quantity column in at least one period.

  • Not Consumed – have no value or a zero value in the Invoiced Quantity column in all periods.

  • Fully Consumed – have zero remaining quantity.

  • Remaining Consumption Above – items for which more than the specified percentage of the quantity remains to be consumed.

  • Remaining Consumption Below – items for which less than the specified percentage of the quantity remains to be consumed.

Search by Name or Code ​

This function filters the displayed items to those containing the specified string. The Code and Description fields are searched.

Printing and Exports ​
